# 08 — P-SL-02 AnchorCarrierProbe: НЕОБЯЗАТЕЛЬНО, ВЫКЛЮЧЕНО, ТОЛЬКО ОДНОРАЗОВОЕ СОХРАНЕНИЕ

> **НЕОБЯЗАТЕЛЬНО.** Не входит в B-01, не нужен для smoke-теста и для T1–T17.
> **ВЫКЛЮЧЕНО ПО УМОЛЧАНИЮ.** Во всех профилях пакета `AnchorProbe.Enabled=false`; ни один скрипт пакета его не
> включает (`SET-PROBE-CONFIG` отказывается записать профиль, где он включён).
> **ТОЛЬКО ОДНОРАЗОВОЕ ТЕСТОВОЕ СОХРАНЕНИЕ.** Зонд **записывает SP-статы** в игру. Никогда не делайте этого на
> сохранении, которое вам нужно.

Метка: **OWNER_RUNTIME_ACTION_REQUIRED (optional)**. Текст DRAFT2 — дословно в `03-PASS-FAIL-RULES.md` (V-7).
Phase 0 не называет ни одного стата безопасным; носитель якоря остаётся DESIGN DECISION, условным к этому зонду и
новому ревью; DRAFT2 его не использует.

## Только если вы решили это делать

1. Всё из `00-RUN-ME-FIRST-RU.md` §2 (резервные копии, игра закрыта). Сделайте **отдельный одноразовый** профиль
   или сохранение, которое не жалко потерять.
2. `scripts\START-NEW-RUN.cmd -GtaRoot "<GTA>" -Label PSL02-<КОНФИГУРАЦИЯ>`.
3. Вручную откройте `scripts\LSAXProbe\probe.ini` в Блокноте и измените **только** эти строки:
   ```
   AnchorProbe.Enabled=true
   AnchorProbe.Consent=I_USE_A_DISPOSABLE_SAVE
   AnchorProbe.CandidateStats=<до 8 целочисленных SP-статов, через запятую>
   ```
   Фраза согласия должна быть **точно** `I_USE_A_DISPOSABLE_SAVE`, иначе зонд остаётся выключенным
   (`ANCHOR_DISABLED` в логе). Выбор статов — ваш и ревьюера (DRAFT2: существуют, сохраняются в SP-сейвах, не
   показаны в меню статистики, не читаются сюжетными скриптами).
4. Загрузите **одноразовое** сохранение. F9 → сохранение → F9 → загрузка → ищите `ANCHOR_READBACK … matchesJournalSeq=n`.
5. **Обязательно F11** до выхода из игры — восстанавливает исходные значения статов (`ANCHOR_RESTORE … ok=1`).
6. Выйдите из игры. `scripts\SET-PROBE-CONFIG.cmd -GtaRoot "<GTA>" -ProbeProfile PSL01` (вернёт выключенное
   состояние; старый `probe.ini` будет сохранён как резервная копия).
7. `scripts\COLLECT-EVIDENCE.cmd -GtaRoot "<GTA>" -Config <КОНФИГУРАЦИЯ> -Phase PSL02`.
8. Одноразовое сохранение **удалите/не используйте** дальше.
