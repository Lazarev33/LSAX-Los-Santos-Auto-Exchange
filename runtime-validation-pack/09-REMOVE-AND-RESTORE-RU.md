# 09 — Удаление зондов и восстановление

Метка: **OWNER_RUNTIME_ACTION_REQUIRED**. Сначала соберите доказательства (`04-RETURN-EVIDENCE-RU.md`).

## 1. Удалить файлы зондов

Игра закрыта. P-SL-02 (если делали): F11 нажат **до** выхода из игры.

```
scripts\REMOVE-PROBES.cmd -GtaRoot "<GTA>"
```

- Удаляет **ровно** файлы из `scripts\LSAXProbe\LSAX-PACK-INSTALL-MANIFEST.tsv` (DLL зондов, всё содержимое
  `LSAXProbeSql\`, установленное пакетом, `probe.ini`) и только если их SHA-256 не изменился. Изменённые файлы
  **не удаляются** — скрипт их перечислит (код выхода 8).
- Папки удаляются только если они **пустые**; ничего не удаляется по маске и рекурсивно.
- Логи и доказательства, отчёты установки и резервные копии установки **остаются**.
- `-RestoreBackups` — вернуть файлы, которые установщик сохранил перед заменой (только туда, где путь свободен).
- `-DeleteEvidence` — дополнительно удалить логи/доказательства (текущий прогон и `runs\`), файлы `p0*.db`
  зонда, отчёты и резервные копии установки: скрипт покажет **каждый** файл и удалит их, только если вы введёте
  `DELETE EVIDENCE`. Сначала обязательно соберите доказательства.

## 2. Восстановить сохранения (вручную)

Скрипты пакета сохранения не трогают. Шаги T2–T4, T13–T17 и P-ID-01 записывали/перезаписывали слоты, T14 — вы
копировали файл вручную. Восстановите папку профиля из **вашей** резервной копии (README-PROBES §11 п. 2).

## 3. Остальное

- Декоратор токена сессии `lsax_p0_sess` существует только пока игра запущена и не сохраняется в сейвах;
  перезапуск игры его убирает. Тег `lsax_p0_tag` (P-ID-01) — так же runtime.
- Папка распакованного пакета (включая `evidence-work\`, `evidence-out\`, `build-local\`) находится вне игры;
  удалите её сами, когда ревьюер подтвердит получение доказательств.
- Проверка, что зондов больше нет: `scripts\HASH-PROBES.cmd -GtaRoot "<GTA>"` сообщит, что манифеста нет (код 6).
