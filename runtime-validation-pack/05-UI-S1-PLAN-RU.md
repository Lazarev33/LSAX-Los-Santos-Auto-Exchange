# 05 — UI-S1: план проверки выполнимости рендерера (только план, кода нет)

Метка: **OWNER + REVIEWER DECISION REQUIRED**. В этом пакете **нет** кода UI-спайка и **нечего запускать**.
UI-S1 не входит в B-01; он закрывает риск **R-UI-1** («no renderer proven on Legacy + SHVDN 3.7 + modpack»).

## Решение пакета: спайк не реализован

Задача разрешала одноразовый спайк только если он **не фиксирует производственную архитектуру**. Любой спайк
UI-S1 должен проверять конкретный рендерер-кандидат OD-1 — то есть выбрать и положить в `scripts` стороннюю
библиотеку (LemonUI, NativeUI) или собственный Scaleform/оверлей. Такой выбор до решения владельца и ревьюера
неявно направлял бы OD-1. Поэтому: **спайк НЕ реализован**, рендерер **не выбран**.

- LemonUI, Scaleform, NativeUI или другой рендерер **не выбраны** как производственная архитектура.
- OD-1 (выбор рендерера) остаётся **OPEN**; основание — только будущие результаты UI-S1 на целевом рантайме.
- Минимальный отладочный рендерер (встроенные `GTA.UI.TextElement`/`ContainerElement` SHVDN) уже описан в
  MASTER §20 и к выбору OD-1 не относится.

## Критерии UI-S1 (MASTER §20, дословно)

> - **Feasibility spike UI-S1 — pass/fail:** (1) renders ru-RU strings containing ё/Ё/ъ and 60+ characters and en-US
>   strings without missing glyphs; (2) documents NBSP/typographic glyph support (R-L10N-1); (3) ≤ 0.5 ms/frame for a
>   20-row list (LSAX stopwatch); (4) keyboard and gamepad navigation; (5) input isolation when another mod's menu is
>   open (no double actions in 20 trials); (6) survives SHVDN `Reload` 20× without exceptions or leaked handlers;
>   (7) 1080p, 1440p and 21:9 layouts legible; (8) 30 min open/close cycling with 0 exceptions. A renderer failing any
>   item is rejected.

Кандидаты из MASTER §20 / OD-1 (без предпочтения): LemonUI (сборка для SHVDN3), NativeUI, собственный Scaleform,
собственный текстовый оверлей.
