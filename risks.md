# LSAX Phase 0 — risks.md (durable working risk log)

Severity: P0 = makes the architecture unsafe or unproven; P1 = material specification/feasibility gap; P2 = tracked,
has mitigation. **Gate (D-GATE-1): every open P0 and P1 blocks SPEC_APPROVED; no stage and no part of any stage
starts before SPEC_APPROVED; there is no Stage 1a exception.** The formal register with triggers, exit criteria and
closure type (OFFLINE / RUNTIME) is `spec/LSAX-RISK-REGISTER.md` (same IDs). Updated in Correction Pass 1 (DRAFT2).
